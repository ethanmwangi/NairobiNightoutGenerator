# Nairobi Night Out Generator 🌃

A vanilla JavaScript app that generates a personalised Nairobi night out plan based on your area, vibe, and budget.

## Why I built this

I'm a software engineering student at USIU rebuilding my JavaScript fundamentals from the ground up — writing real code, not just prompting AI. This is project 1 of 3 in my JS fundamentals series.

## How it works

Pick your area, vibe, and budget. Hit generate. The app filters through a curated list of Nairobi spots and tells you where to go.

## Built with

- HTML
- CSS (neon UI)
-  JavaScript
